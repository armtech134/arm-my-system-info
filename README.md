# Welcome to About Device
About Device is a Windows Application that lets you know many things regarding your system effortlessly, Without having to navigate through multiple windows.
## Build Instructions:
- Install Uv, Python and Git, if you don't have them already.
```
winget install python.python.3.14 astral-sh.uv git.git
```
- Restart your terminal
- Clone the Repo.
```
git clone https://github.com/armtech134/about-device
```
- Go inside the directory.
```
cd about-device
```
- Sync the project.
```
uv sync
```
- Start the App.
```
uv run src\main.py
```
That's it!
